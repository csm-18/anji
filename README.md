# anji

## Development Environment

- Operating System: Linux Mint
- Compiler: GCC(g++) 12.5.0
- Build Tool: GNU Make 4.3
- Code Editor: VS Code (with clangd) (using bear tool for generating compile_commands.json for clangd to work)

## Building The Project

### For Development

```bash
make
```

### For Release Build

```bash
make release
```

### Clean The Build Output

```bash
make clean
```
